تضم **المكتبة** موارد لكل صف مصنفة حسب المادة: روابط أو ملفات (PDF أو مستند أو صورة أو فيديو حتى 1 ميجابايت).

يضيف الموظفون والمعلمون موردًا عبر **مورد جديد**: العنوان ووصف اختياري والصف ووسوم المواد ورابط أو ملف، ولا يختار المعلم إلا الصفوف التي يدرّسها. ويرى الطلاب وأولياء الأمور موارد صف الطالب في **المكتبة** ضمن بوابتهم مع تصفية حسب المادة.
